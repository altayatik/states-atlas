# Altay & Aidi's Travel Atlas

A personal travel atlas built with React, Vite, MapLibre, local static map data, Firebase Firestore, and Firebase Cloud Functions. The app includes the state-level road atlas and the National Parks rankings page.

- Source folder: `/Users/altayatik/Desktop/atlas/states-atlas`
- Public deployment repo: `https://github.com/altayatik/atlas`
- Public URL: `https://altayatik.com/atlas/`
- Editor URL: `https://altayatik.com/atlas/#/edit`

The public app is read-only. The editor is protected by a Firebase Cloud Function secret phrase gate.

## Local Dev

```bash
npm install
npm --prefix functions install
npm run dev
```

The Vite base path is `/atlas/`.

## Frontend Environment

Copy `.env.example` to `.env.local` and fill in the Firebase Web app config:

```bash
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
VITE_FIREBASE_MEASUREMENT_ID=
VITE_FIREBASE_FUNCTIONS_REGION=us-central1
```

Firebase Web config is public client configuration, but `.env.local` is still ignored so local machine settings do not churn in Git.

## Firebase Setup

Enable:

- Firestore Database in Native mode
- Cloud Functions
- Cloud Secret Manager for function secrets

Use Firebase CLI:

```bash
npx firebase-tools login
npx firebase-tools use --add
```

## Firestore Collections

### `stateTravelEntries`

Document ID is the state/province code, such as `CA`, `AK`, or `CAN`.

Fields:

- `state_code`
- `state_name`
- `status`
- `first_visited_year`
- `favorite_memory`
- `badges`
- `vibe_rating`
- `honorable_mention`
- `cities_visited`
- `parks_visited`
- `created_at`
- `updated_at`

### `parkRankings`

Document ID is generated by Firestore or imported from Supabase `id`.

Fields:

- `park_name`
- `park_code`
- `is_custom`
- `scenery`
- `visitor_center`
- `facilities`
- `trails`
- `roads`
- `notes`
- `visited_date`
- `honorable_mention`
- `created_at`
- `updated_at`

## Security Rules

Rules live in `firestore.rules`.

- Public reads are allowed for `stateTravelEntries` and `parkRankings`.
- Direct public writes are denied.
- Writes go through Firebase Cloud Functions using the Admin SDK.

Deploy rules:

```bash
npx firebase-tools deploy --only firestore:rules
```

## Cloud Functions

Functions:

- `statesAdmin`
- `parksAdmin`

Secrets:

```bash
npx firebase-tools functions:secrets:set ADMIN_SECRET_PHRASE
npx firebase-tools functions:secrets:set ADMIN_TOKEN_SECRET
```

Generate `ADMIN_TOKEN_SECRET` with:

```bash
openssl rand -base64 32
```

Deploy:

```bash
npx firebase-tools deploy --only functions
```

Security behavior:

- Empty phrase does not unlock.
- Wrong phrase does not unlock.
- Correct phrase returns a 2-hour signed admin token.
- Frontend stores only the token in `sessionStorage`.
- The real phrase lives only in Firebase Functions secrets.

## Supabase Backup And Import

Supabase exports were saved locally in:

```text
migration-backups/state_travel_entries.supabase-export.json
migration-backups/park_rankings.supabase-export.json
```

The folder is ignored and should not be committed.

Import both into Firestore:

```bash
gcloud auth application-default login
npm --prefix functions run import:backup -- \
  --states=./migration-backups/state_travel_entries.supabase-export.json \
  --parks=./migration-backups/park_rankings.supabase-export.json
```

Or use a service account JSON outside the repo:

```bash
GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json \
  npm --prefix functions run import:backup -- \
  --states=./migration-backups/state_travel_entries.supabase-export.json \
  --parks=./migration-backups/park_rankings.supabase-export.json
```

Do not commit service account files.

## Troubleshooting

If the editor says Firebase unlock is not configured:

1. Confirm `.env.local` has the Firebase web config before building.
2. Confirm `ADMIN_SECRET_PHRASE` and `ADMIN_TOKEN_SECRET` are set.
3. Confirm both functions are deployed.
4. Rebuild and redeploy the frontend.

If an old browser token fails:

```js
sessionStorage.removeItem('statesAtlasAdminToken')
sessionStorage.removeItem('travelAtlasParkAdminToken')
```
